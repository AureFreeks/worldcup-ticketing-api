To install dependencies:
```sh
bun install
```
To run:

ouvrir deux terminal sur la racine du projet :

Sur l'un faire  : 

```sh
docker compose up
```
Sur l'autre faire  :
```sh
bun run seed
bun run dev
```


open http://localhost:3000/
